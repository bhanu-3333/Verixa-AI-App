# Splash Screen Assets

This folder contains the images required for the Verixa AI splash/loading screen.

## Required Files

1. **sky.png** — Blue sky background image (full-screen)
2. **woman.png** — Transparent PNG of woman performing sign language

## Instructions

1. Save the **blue sky** image as: `sky.png`
2. Save the **transparent woman** PNG as: `woman.png`
3. Both files should be placed in this folder (`assets/images/splash/`)

The splash screen will automatically use these images once they're added.

---

**Note:** The woman image must be a PNG with transparent background (no white or black box around her).
